Not used — and why not
dbt
planned but dropped. DuckDB SQL in run_pipeline.py is simpler for a single-file warehouse with no incremental loads.
sentence-transformers
available in code but disabled. pure normalization + MD5 gives good enough matching without a 200MB model download.
Airflow / Prefect
no scheduler needed. the pipeline is a single script that runs in 45 seconds. not worth the overhead.
tradeoffs — what we chose and what we gave up
Design Tradeoffs
every architecture is a set of bets · here are ours
Mark (fair_value / cost) as the core signal
Chose
Ratio that BDCs actually report and that drives their NAV. Comparable across positions of different sizes.
Gave up
Raw fair value or spread-to-benchmark. Cost can change in restructuring, making the ratio noisy. Mitigated with cost stability filter.
Simple rule wins for Target A (crosses 0.80)
Chose
Report honestly that sort-by-lowest-mark beats the model (PR-AUC 0.227 vs 0.209). Threshold-crossing is nearly deterministic from current mark.
Gave up
Could have added features until the model beat the rule. Would be overfitting to noise. ML adds real value only on Target B (big markdown).
Entity resolution without embeddings
Chose
Normalize + MD5 hash. Deterministic, fast, no model dependency. Handles 95%+ of variation (punctuation, legal suffixes).
Gave up
Fuzzy matches across name changes. Code for embedding path exists and can be enabled. Would add 200MB dependency + 30s runtime.
Cost-stable drift only for laggard alerts
Chose
Only fire when cutting manager's cost is stable (0.67x–1.5x of prior Q). Ensures mark cut reflects a genuine credit call, not a portfolio reshuffle.
Gave up
Alerts from managers actively trading the position. May miss real cuts bundled with sells. needs_review flag covers borderline cases.
7 quarters of history
Chose
Use all available SEC DERA data (Q4 2022 – Q3 2024). Out-of-sample validation on both targets. Infrastructure ready for more quarters.
Gave up
Statistical power. Short history means wide confidence intervals. Results are honest about this limitation.
